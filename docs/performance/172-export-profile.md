# Issue #172 export profile

The synthetic fixture is generated by `src/anki-export.profile.test.ts`. It
contains 2,000 standard Notes in one Deck, one Card and one image media
reference per Note, and one shared verified 1×1 PNG blob. Scheduling, review
history, and media export are enabled; the fixture has no review rows. The
timer covers `exportAnkiPackage()`, including the consistent snapshot, export
preparation, package serialization, and archive validation. Fixture creation
and the first warm-up export are excluded. Five timed exports are measured and
the median is reported.

Run from the repository root after `npm ci`:

```powershell
$env:EXPORT_PROFILE_NOTES = '2000'
npx vitest run src/anki-export.profile.test.ts --reporter=verbose
```

Environment: Windows 11 10.0.22631, Node.js 22.18.0, npm 11.16.0, Vitest
4.1.11, SQL.js 1.12.0. Both runs used the same worktree machine, fixture
generator, and command. The baseline run temporarily used `origin/main`'s
`src/anki-export.ts`; the post-change run used the indexed implementation.

| Version | Samples (ms) | Median (ms) | Notes / Cards / References / Blobs |
| --- | --- | ---: | --- |
| Before | 427.9, 437.4, 438.4, 457.9, 466.9 | 438.4 | 2,000 / 2,000 / 2,000 / 1 |
| After | 312.5, 320.6, 322.3, 333.4, 340.9 | 322.3 | 2,000 / 2,000 / 2,000 / 1 |

The measured median decreased by 26.5% on this fixture. These measurements are
descriptive and are not used as a CI threshold.
