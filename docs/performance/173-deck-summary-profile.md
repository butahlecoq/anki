# Issue #173 Deck summary profile

The synthetic fixture is generated by `src/collection.summaries.profile.test.ts`.
It contains 32 root Decks, six child Decks per root, two grandchildren per
child, and eight empty Decks. Each populated Deck holds 12 Notes and Cards, for
7,296 of each across 616 Decks. It also has 1,460 review rows and one Custom
Study Session containing 1,043 Cards. The timer covers five `summaries()` calls
after one warm-up call; fixture creation is excluded and the median is
reported.

Run from the repository root after `npm ci`:

```powershell
$env:SUMMARY_PROFILE = '1'
npx vitest run src/collection.summaries.profile.test.ts --reporter=verbose
```

Environment: Windows 11 10.0.22631, Node.js 22.18.0, npm 11.16.0, Vitest
4.1.11. Both runs used the same worktree machine, fixture generator, and
command. The baseline run temporarily used `origin/main`'s `src/collection.ts`;
the post-change run used the aggregated implementation.

| Version | Samples (ms) | Median (ms) | Decks / Notes / Cards / Reviews / Session Cards |
| --- | --- | ---: | --- |
| Before | 261.0, 291.8, 309.5, 315.2, 327.2 | 309.5 | 616 / 7,296 / 7,296 / 1,460 / 1,043 |
